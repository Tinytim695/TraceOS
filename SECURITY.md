# Security Policy

TraceOS is intended for legitimate administration, incident response, digital forensics, CTFs, and security testing on systems you are authorized to assess.

## Reporting a vulnerability

Please do not post credentials, private data, exploit details for live targets, or other sensitive material in a public issue.

Use GitHub's private vulnerability reporting or Security Advisories for this repository when available. If private reporting is not enabled, contact the repository maintainer through GitHub before publishing sensitive details.

## Scope

Security reports are especially useful for:

- credential or secret exposure
- unsafe privilege escalation
- evidence-integrity issues
- unintended network activity
- destructive storage behaviour
- malicious or compromised build dependencies
- GitHub Actions or release-pipeline weaknesses

Please include the affected path, a concise description, reproduction steps where safe, and the impact you observed.
